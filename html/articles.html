What I Learned Styling a Website with CSS

While styling my portfolio, I learned how CSS can turn plain HTML into a consistent, easy-to-use website.

  • Reusable styles make multiple pages feel like parts of the same website.
  • Flexbox is useful for aligning items in a row, like a logo and navigation links.
  • CSS Grid helps organize content into columns, such as project, experience, and education sections.
  • Spacing, readable colors, and clear headings make content easier to scan.
  • Media queries let a layout adapt to smaller screens instead of overflowing.

Building this site helped me understand that good styling is not only about appearance; it also makes the content clearer and easier to navigate.
